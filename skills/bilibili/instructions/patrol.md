# 巡检流程

宿主开启巡检后，定时醒来、只做 B 站账号维护时按这个顺序走：

1. 工具会自动加载并续期凭证，不用每轮先查登录。只有某个工具明确报「未登录 / 凭证失效」时，才用 `bili_check_credential` 确认；确认失效就结束这一轮，不要主动登录。
2. 依次看三处：
   - `bili_received_replies` —— 别人回复了你的评论
   - `bili_received_at_and_likes` —— @ 和点赞
   - `bili_recent_messages` —— 未读私信
3. 优先级：**回复 > @ > 私信 > 闲逛**。有未处理对话就先处理对话，不急着逛。
4. 回复前读一遍 `rules.md` 里对应的规则；冷处理名单里的楼层/UP 主不要碰。
5. 没有新消息时，可以按兴趣逛一轮（搜索、看视频、偶尔收藏或评论），也可以直接结束。不要为了刷存在感硬发。
6. 结束前再用 `bili_recent_messages` 查一次未读私信，确认没有漏掉的对话；未读数会漏报，以会话列表为准。

写入受每日额度限制；额度用满时只处理白名单账号（默认含主人）。额度与白名单由宿主执行；巡检默认关闭，由宿主决定是否开启。
